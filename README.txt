Highend Technologies - Final Order Ready Email Template

This package includes:
- order-ready-template.html   Editable template with placeholders
- order-ready-preview.html    Filled preview version
- assets/                     Supporting image and SVG icon assets

Editable placeholders:
- {{CLIENT_NAME}}
- {{ORDER_NUMBER}}
- {{ORDER_URL}}

Included final updates:
- Space and astronaut themed mailbox illustration
- User-provided SVG icons for the three body feature blocks
- Real logo placed in HTML above the header and footer background images
- Clickable footer email and phone number
- 10 px light blue border around the whole template
- Soft shadow around the full email card
- Inclusive Sans loaded from Google Fonts

Note: Some email clients may fall back to Arial if remote fonts or SVG are blocked.
